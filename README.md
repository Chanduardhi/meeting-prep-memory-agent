# AI Meeting Prep & Contact Memory Agent

An intelligent agent built with **Vectorize Hindsight** for persistent client memory, **Groq API** for executive briefings, and a **Streamlit** user interface.

## Features
- **Multi-Bank Architecture**: Isolated Hindsight memory banks per contact (`bank_client_*`).
- **Automated Logging**: Tracks debriefs and reminders in CSV spreadsheets.
- **Executive Briefings**: Generates instant summaries on client communication preferences and commitment.
